# Week 3 Assignment: Grade Reporter & Bug Hunt

This repository contains my Week 3 Python assignment on conditions and loops.

* `grade_reporter.py` - Uses a `for` loop, conditions, counters, and a running total to calculate grades, passes, failures, and the average score.
* `bug_hunt.py` - Fixes three bugs in a `while` loop program and calculates the sum of numbers from 1 to 5.

The hardest bug to find was the loop condition because the program could run without showing an error message but still produce the wrong answer. I knew something was wrong because the program was supposed to add 1, 2, 3, 4, and 5 and produce 15, but the loop condition stopped before including 5.
